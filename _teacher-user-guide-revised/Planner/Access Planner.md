<h2>Access Planner</h2>
<hr>
<p>Planner allows you to manage your personal learning schedule and timetable.
You can create events or import your school timetable/calendar into the
Planner and view Assignments which are due soon.</p>
<p><u>Note</u>: Please ensure you have enabled pop-ups before accessing assignments
or resources attached to events. You may refer to the <a href="https://www.learning.moe.edu.sg/files/Userguide/Downloadable%20Resources/Enable-Pop-ups-Guide.pdf" rel="noopener noreferrer nofollow" target="_blank"><u>Enable Pop-Ups guide</u></a> on
how you can enable pop-ups for your device.</p>
<h2>Navigating to the Page</h2>
<hr>
<ol>
<li>
<p>There are three ways to access the <strong>Planner:</strong>
</p>
<ol data-tight="true" class="tight">
<li>
<p>From the home page, click the <strong>View Planner</strong> icon</p>
<div class="isomer-image-wrapper">
<img style="box-sizing: inherit; font-family: Lato, sans-serif; max-width: 100%; height: auto; display: inline; margin: auto; width: 1.5rem;" height="auto" width="100%" src="https://www.learning.moe.edu.sg/images/Icons/CalendarOpen.svg">
</div>
</li>
<li>
<p>Open the left menu and click <strong>Planner</strong>.</p>
</li>
<li>
<p>Enter a Class Group and click the <strong>Planner</strong> tab.</p>
<div class="isomer-image-wrapper">
<img style="box-sizing: inherit; font-family: Lato, sans-serif; max-width: 100%; height: auto; display: block; margin: auto; width: 805.328px;" height="auto" width="100%" alt="Access Planner" src="https://www.learning.moe.edu.sg/images/2Teacher/P-ClassGroupPlanner.png">
</div>
</li>
</ol>
</li>
<li>
<p>From the Planner dropdown list, select the <strong>Class Group(s)</strong> you
wish to view the events for. Click <strong>Apply</strong> to proceed. The
total number of Class Groups selected is indicated in parenthesis.</p>
<p><u>Note</u>:</p>
<ul data-tight="true" class="tight">
<li>
<p>When viewing the Planner from a Class Group, you will only be able to
view Class Group Events for that particular Class Group.</p>
</li>
<li>
<p>To view certain Class Group Events as default, pin those Class Groups.
You may refer to <a href="https://www.learning.moe.edu.sg/teacher-user-guide/organise/pin-class-groups/" rel="noopener noreferrer nofollow" target="_blank"><u>Pin Class Groups</u></a> for
how to do so.</p>
</li>
</ul>
</li>
<li>
<p>The Planner may be viewed by Day, Week or Month. Click on the relevant
tab for your preferred view.</p>
</li>
<li>
<p>To view other dates, click on the <strong>Left</strong> or <strong>Right Arrows</strong> to
see the past or future respectively.</p>
</li>
<li>
<p>To return to the current date, click <strong>Today</strong>.</p>
</li>
<li>
<p>To know what events are happening at the moment, refer to the Red Line.</p>
<div class="isomer-image-wrapper">
<img style="width: 100%" height="auto" width="100%" alt="Access Planner" src="https://www.learning.moe.edu.sg/images/2Teacher/P-Calendar.png">
</div>
<p>
<br><u> Did You Know</u>:</p>
</li>
</ol>
<p>Assignment cards will appear under day view if there are assignments due
today or in the next 3 days.</p>
<h2>Import Events</h2>
<hr>
<p>You may import other calendars into the SLS Planner.</p>
<ol>
<li>
<p>On the Planner page, click <strong>Import</strong>.</p>
</li>
<li>
<p>Upload your calendar file and click&nbsp;<strong>Upload</strong>&nbsp;to
proceed.</p>
</li>
<li>
<p>Only Events that meet the requirement will be imported.</p>
<ol>
<li>
<p><strong>Supported Event Details</strong>
</p>
<ul>
<li>
<p>Event name (50 characters)</p>
</li>
<li>
<p>Event description (2000 characters)</p>
</li>
<li>
<p>Event Start Date and Time</p>
</li>
<li>
<p>Event End Date and Time</p>
</li>
<li>
<p>All Day Events</p>
</li>
</ul>
</li>
<li>
<p><strong>Events that will not be imported:</strong>
</p>
<ul>
<li>
<p>Events outside of the SLS calendar year</p>
</li>
<li>
<p>Recurring events lasting more than one day</p>
</li>
</ul>
</li>
</ol>
</li>
<li>
<p><u>Note:</u> Only the .ics file format is supported. <a href="https://www.learning.moe.edu.sg/teacher-user-guide/author/file-size-limits/" rel="noopener noreferrer nofollow" target="_blank"><u>File name character limits and file size limits</u></a> apply.</p>
</li>
</ol>
