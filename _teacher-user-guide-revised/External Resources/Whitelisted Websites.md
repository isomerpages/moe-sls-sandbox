<h3>Embed Whitelisted Websites</h3>
<hr>
<p>To identify the newly whitelisted websites, press Ctrl+F and type "NEW!"
in the search bar.</p>
<p>Schools are advised to be mindful of the latest age advisories for whitelisted
sites. Users can check the website description for age advisories on the
listed sites in SLS External Resources by clicking on the <strong>View Details</strong> icon
.</p>
<p>When using sites with AI affordances, schools should refer to the <a href="https://www.learning.moe.edu.sg/ai-in-sls/responsible-ai/ai-in-education-ethics-framework/" rel="noopener noreferrer nofollow" target="_blank"><u>MOE AIEd Ethics Framework</u></a> for
comprehensive guidelines.</p>
<p><u>Notes</u>:</p>
<ol>
<li>
<p>If you would like SLS to consider a website for whitelisting, please submit
a request through the <a href="https://go.gov.sg/sls-whitelist-form" rel="noopener noreferrer nofollow" target="_blank"><u>Website Whitelisting Form</u></a>.</p>
</li>
<li>
<p>If you are unable to embed a website, the website may have been <a href="https://www.learning.moe.edu.sg/teacher-user-guide/discover/previously-whitelisted-and-non-whitelisted-websites/" rel="noopener noreferrer nofollow" target="_blank"><u>removed from whitelisting</u></a>.
Alternatively, you may&nbsp;email us&nbsp;at <a href="https://www.learning.moe.edu.sg/ai-in-sls/responsible-ai/ai-in-education-ethics-framework/" rel="noopener noreferrer nofollow" target="_blank"><u>helpdesk@sls.ufinity.com</u></a>.</p>
<p></p>
</li>
</ol>
<h3>Whitelisted Websites and URLs (Using Site URL)</h3>
<hr>
<p>To embed a whitelisted website using site URL:</p>
<ol>
<li>
<p>In Module Editor page, hover over Text/Media found within the Component
Bar and select Website.</p>
</li>
<li>
<p>On the Embed Website subpage, select the radio button side Enter URL or
Enter Code.</p>
</li>
<li>
<p><u>Note</u>: Search in the tables below to determine if a whitelisted
website can be embedded via URL or Code.</p>
</li>
<li>
<p>Alternatively, click <strong>Choose From Approved Websites</strong> to select
a whitelisted website. Click the <strong>Website card</strong>, followed
by <strong>Choose</strong> to proceed.</p>
</li>
<li>
<p>The URL or Code would be displaced in the text box.</p>
</li>
<li>
<p>You can adjust the Height and Width (in pixel) for the whitelisted website
display.</p>
</li>
<li>
<p>Click <strong>Save</strong> to confirm.</p>
</li>
</ol>

<li>
<p>In Module Editor, click <strong>Add Component</strong> and select the component
of your choice.</p>
</li>

<p>In the Rich Text Editor, click the <strong>Embed</strong> icon and select
the <strong>Enter code to embed</strong> radio button.</p>
</li>

<p>Insert the URL in the Embed Subpage and click the <strong>Add</strong> button.</p>
</li>
<li>
<p>The embedded website will be shown in the Component box.</p>
</li>
<li>
<p>Click <strong>Save</strong> when done.</p>
