<h2>Create New Folders</h2>
<hr>
<h3>Create a New Folder in My Modules Tab</h3>
<hr>
<ol data-tight="true" class="tight">
<li>
<p>Open the left menu from the header on the homepage. Click <strong>Resources</strong>,
followed by <strong>My Drive</strong>. By default, you will be in the My
Modules tab.</p>
</li>
<li>
<p>On the My Modules tab, click <strong>Create/Edit</strong>, followed by <strong>New Folder</strong>.</p>
<div class="isomer-image-wrapper">
<img style="box-sizing: inherit; font-family: Lato, sans-serif; max-width: 100%; height: auto; display: block; margin: auto; width: 825.328px;" height="auto" width="100%" alt="Create New Folders" src="https://www.learning.moe.edu.sg/images/2Teacher/O-NewFolder.png">
</div>
</li>
<li>
<p>In the Add New Folder subpage, enter a Folder Name.</p>
</li>
<li>
<p>Click <strong>Add New Folder</strong> once done.</p>
</li>
<li>
<p>You can create sub-folders in folders by following the above steps.</p>
</li>
</ol>
<h3>Folders in Multiple Levels</h3>
<hr>
<p>When browsing a folder under <strong>My Modules</strong> tab, you will see
the names of the folders by levels in the horizontal line of text in the
table header (breadcrumb). Clicking the folder's title in the breadcrumb
will bring you directly to the folder.</p>
<p>If there are too many folder levels, clicking "..." will bring up a dropdown
list of all the levels in between.</p>
<div class="isomer-image-wrapper">
<img style="width: 100%" height="auto" width="100%" alt="Create New Folders" src="https://www.learning.moe.edu.sg/images/2Teacher/O-MultipleFolders.png">
</div>
<p><u>Did You Know</u>:</p>
<p>By default, the resources in My Drive are sorted by folders, followed
by files, based on the latest modified date.</p>
<h2>Manage Folders</h2>
<hr>
<h3>Move Modules to a Folder</h3>
<hr>
<p>You can move an existing Module from one folder to another.</p>
<ol data-tight="true" class="tight">
<li>
<p>To move an existing Module into a folder, you can click the <strong>Overflow</strong> (<strong>3-dot</strong> icon)
and select <strong>Move</strong>. You can also select the Module using the
checkboxes on the left and then click <strong>Move</strong>. You may move
two or more Modules in one go.</p>
</li>
<li>
<p>In the Move Module subpage, select the folder to move the Module to. You
can also create a <strong>New Folder</strong> within My Modules folder from
this subpage.
<br>
</p>
<div class="isomer-image-wrapper">
<img style="box-sizing: inherit; font-family: Lato, sans-serif; max-width: 100%; height: auto; display: block; margin: auto; width: 825.328px;" height="auto" width="100%" alt="Manage Folders" src="https://www.learning.moe.edu.sg/images/2Teacher/O-MoveMultiple.png">
</div>
</li>
<li>
<p>Click <strong>Move</strong>.</p>
</li>
</ol>
<h3>Rename a Folder</h3>
<hr>
<ol data-tight="true" class="tight">
<li>
<p>In the listing, locate a folder and click the <strong>Overflow</strong> (<strong>3-dot</strong> icon),
followed by <strong>Rename</strong>.</p>
</li>
<li>
<p>In the Rename Folder subpage, enter a new title.</p>
</li>
<li>
<p>Click <strong>Rename</strong> to save the new name.</p>
</li>
</ol>
<h3>Delete a Folder</h3>
<hr>
<ol data-tight="true" class="tight">
<li>
<p>In the listing, locate a folder and click the <strong>Overflow</strong> (<strong>3-dot</strong> icon),
followed by <strong>Move to Trash</strong>. Alternatively, you can select
multiple folders using the checkboxes on the left and click <strong>Move to Trash</strong> in
the table header.</p>
</li>
<li>
<p>If you have deleted a folder by mistake, it can be restored from the <strong>Trash</strong> tab.</p>
</li>
</ol>
<h3>Copy Modules within My Drive</h3>
<hr>
<p>You can make a copy of an existing Module under My Modules tab.</p>
<ol data-tight="true" class="tight">
<li>
<p>To make a copy of an existing Resource, click the <strong>Overflow</strong> (<strong>3-dot</strong> icon)
and click <strong>Make a Copy</strong>.</p>
</li>
<li>
<p>In the Make a copy of a Module subpage, select the folder to copy the
Module to. By default, the <strong>My Modules</strong> folder is chosen for
you. You can also create a <strong>New Folder</strong> within My Modules
folder if necessary.</p>
</li>
<li>
<p>Click <strong>Copy</strong>.</p>
</li>
</ol>
<h2>Delete Resources</h2>
<hr>
<p><strong>Resources</strong> (Modules and Folders) found under My Modules
tab can be deleted if you no longer need them.</p>
<h3>Move Resources to Trash</h3>
<hr>
<ol data-tight="true" class="tight">
<li>
<p>Open the left menu from the header on the homepage. Click <strong>Resources</strong>,
followed by <strong>My Drive</strong>. By default, you will be in the My
Modules tab.</p>
</li>
<li>
<p>In the listing, click the <strong>Overflow</strong> (<strong>3-dot</strong> icon)
followed by <strong>Move to Trash</strong>.</p>
</li>
<li>
<p>To move multiple Resources to trash at once, select the checkboxes beside
the Resource Title. Click <strong>Move to Trash</strong> through the header.</p>
</li>
<li>
<p>You may also click <strong>Move to Trash</strong> after opening up a Module.
From the Module View page, open the right menu and select <strong>Move to Trash</strong>.</p>
</li>
<li>
<p>To restore a Resource that was deleted by accident, click <a href="https://www.learning.moe.edu.sg/teacher-user-guide/organise/restore-resources-from-trash/" rel="noopener noreferrer nofollow" target="_blank"><u>Restore from the Trash tab</u></a>.</p>
</li>
</ol>
<h3>Delete Resources Permanently</h3>
<hr>
<p>You can choose to permanently delete Resources from the <strong>Trash</strong> tab.</p>
<ol data-tight="true" class="tight">
<li>
<p>To delete a resource permanently, click the <strong>Overflow</strong> (<strong>3-dot</strong> icon)
and select <strong>Delete Forever</strong>.</p>
</li>
<li>
<p>Click <strong>OK</strong> in the confirmation prompt.</p>
</li>
<li>
<p>To delete multiple Resources at once, select the checkboxes beside the
Resource Title. Click <strong>Delete Forever</strong> through the header.</p>
</li>
</ol>
<h3>Restore Resources from Trash</h3>
<hr>
<p>Resources found under the <strong>Trash</strong> tab can be restored to
their original locations.</p>
<ol data-tight="true" class="tight">
<li>
<p>To restore a resource, click the <strong>Overflow</strong> (<strong>3-dot</strong> icon)
and select <strong>Restore</strong>.</p>
</li>
<li>
<p>To restore multiple Resources at once, select the checkboxes beside the
Resource Title. Click <strong>Restore</strong> through the header.</p>
</li>
<li>
<p>Restored Resources will appear under My Modules tab.</p>
</li>
</ol>
