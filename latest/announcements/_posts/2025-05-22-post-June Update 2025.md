<h1>What's new in June 2025 Update</h1>

<p>This list details the changes users can expect in the upcoming SLS June 2025 Update, which will be rolled out on 25 June 2025. Please note that SLS will be unavailable from 24 June 2025 00:00 to 25 June 2025 23:00 to facilitate this update.</p>

<h2><img src="/images/Icons/Star.svg" style="width:3rem; display: inline;">Features for All Users</h2>

<ol>

<li><details><summary><h4 style="margin: 0; display: inline;">Assessments</h4></summary>
<ul>
<li>Teachers and students can log in directly for e-assessments using SLS or MIMS Login. They will be brought directly to their Assessments listing page upon logging in.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Assignments</h4></summary>

<div style="margin-left: 20px;">

<details><summary><strong>Annotation Enhancements</strong></summary>
<ul>
<li>Teachers and students can more easily differentiate annotations made by a teacher (underline) from those by students (highlight).</li>
<li>For annotations made on questions, teachers and students can view the question number with question text as the header of each annotation card.</li>
</ul>
</details>

<details><summary><strong>Due Date Tracking</strong></summary>
<ul>
<li>Teachers and students can filter assignments by multiple status types: Incomplete, Overdue assignments, Overdue Sections, Due in 3 Days, Complete, and Upcoming.</li>
</ul>
</details>

<details><summary><strong>Feedback Fields</strong></summary>
<ul>
<li>"Teacher Comments" is now renamed to "Feedback" in FRQs. The existing "Feedback" field is removed.</li>
</ul>
</details>

<details><summary><strong>Past Assignments</strong></summary>
<ul>
<li>Teachers and students can view assignments from past class groups in the Assignments listing page.</li>
</ul>
</details>

</div>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Planner Enhancements</h4></summary>
<ul>
<li>Tasks with deadlines can be created from multiple entry points: task list, module plan, section cover, and learning progress (students only).</li>
<li>Resources such as sections and modules can be attached to tasks.</li>
<li>Students will be prompted when marking incomplete attachments as complete.</li>
<li>Students can create goals from learning progress and attach relevant self-study resources.</li>
<li>Planner calendar range extended to include the year before and after the current year. Teachers can clear planner events en-masse.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Search Enhancements</h4></summary>
<ul>
<li>Filtered search results are shown based on assigned and followed subjects and levels.</li>
<li>Subjects and levels appear paired in search results for clarity.</li>
<li>Modules include a clickable icon in search results that opens them in a new tab.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Avatar Enhancements</h4></summary>
<ul>
<li>Clicking on non-AI avatars shows the user's profile.</li>
</ul>
</details></li>

</ol>

<h2><img src="/images/Icons/Star.svg" style="width:3rem; display: inline;">Features for Teachers</h2>

<ol>

<li><details><summary><h4 style="margin: 0; display: inline;">Account Management</h4></summary>
<ul>
<li>SLS email notification is sent if an account becomes inactive due to MIMS inactivity. Deactivation happens after a 120-hour countdown.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Authoring</h4></summary>

<div style="margin-left: 20px;">

<details><summary><strong>Gamification Enhancements</strong></summary>
<ul>
<li>Import gamification settings (Details, XP, Game Stories, Collectibles, Leaderboard) from other modules.</li>
<li>Duplicate game stories and collectibles.</li>
<li>Add gamification conditions as prerequisites for sections/activities.</li>
<li>Toggle XP visibility for students; XP will be hidden but conditions still awarded.</li>
</ul>
</details>

<details><summary><strong>Live Chat</strong></summary>
<ul>
<li>Set up Live Chat for team and non-team discussions.</li>
<li>View live posts in active rooms.</li>
<li>Manually close rooms; archived as discussion posts with stored comments.</li>
<li>Set time limits to auto-close rooms.</li>
<li>Not available in self-study modules or preview-as-student mode.</li>
</ul>
</details>

<details><summary><strong>Hide Question Number</strong></summary>
<ul>
<li>Hide question/component numbers in quizzes using Quiz Details settings.</li>
</ul>
</details>

<details><summary><strong>Click-and-Drop Enhancements</strong></summary>
<ul>
<li>Improved precision when placing or repositioning options.</li>
</ul>
</details>

<details><summary><strong>Component Card Enhancements</strong></summary>
<ul>
<li>Component number and body text are shown as headers during view and authoring.</li>
</ul>
</details>

</div>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Authoring Copilot (ACP) Enhancements</h4></summary>
<ul>
<li>Google Slides, Docs and Sheets can be uploaded to the Knowledge Base for ACP and Learning Assistant (from 4 July 2025).</li>
<li>ACP is accessible from Add New and Create/Edit subpages.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Assessments</h4></summary>
<ul>
<li>Assessments are accessed via a dedicated page (not grouped with assignments).</li>
<li>Quick switch to student view available via shortcut.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Assignments</h4></summary>

<div style="margin-left: 20px;">

<details><summary><strong>@-Mention</strong></summary>
<ul>
<li>Use @-mention in notes, annotations, comments, posts and feedback to notify others. List is based on assignees and teachers.</li>
</ul>
</details>

<details><summary><strong>Annotation Enhancements</strong></summary>
<ul>
<li>Share notes/annotations with all assignees. Students see shared content in their view.</li>
<li>Choose to notify students when sharing notes/annotations.</li>
</ul>
</details>

<details><summary><strong>Heatmap Enhancements</strong></summary>
<ul>
<li>Click heatmap cells to access student activity pages.</li>
<li>View section start/due dates when filtering by section. Click to adjust in Assignment Settings.</li>
</ul>
</details>

</div>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Annotated Feedback Assistant (AFA)</h4></summary>
<ul>
<li>Set a maximum number of drafts students can submit before final submission.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Adaptive Learning System (ALS)</h4></summary>
<ul>
<li>Filter student view in ALS Dashboard by Learning Outcome.</li>
<li>Sort students by ability score; see score snapshots after adaptive sections.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">ShortAnsFA Enhancements</h4></summary>
<ul>
<li>Students can submit Google Slides, Docs and Sheets in FRQs.</li>
<li>Teachers can edit feedback criteria after FRQ/ARQ release.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Data Assistant (DAT) Enhancements</h4></summary>
<ul>
<li>Save DAT analysis results for FRQs and discussions.</li>
<li>Enable quiz-level feedback for students based on quiz performance.</li>
<li>Analyze overall class quiz performance using DAT.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Error Tracker Enhancements</h4></summary>
<ul>
<li>Access selected student's error tracker from Students tab.</li>
<li>In student view, see list of attempted modules with error counts.</li>
<li>Filter by month range and error tag.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Starred Resources</h4></summary>
<ul>
<li>Teachers can star/unstar class group and community resources.</li>
<li>Can also add from starred class group resources.</li>
</ul>
</details></li>

</ol>

<h2><img src="/images/Icons/Star.svg" style="width:3rem; display: inline;">Features for Students</h2>

<ol>

<li><details><summary><h4 style="margin: 0; display: inline;">Access Control</h4></summary>
<ul>
<li>Students using a temporary passcode (expired password) are redirected to intended landing page.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Assessments</h4></summary>
<ul>
<li>Students can access all assessments via listing page.</li>
<li>Cannot view module structure for upcoming or locked assessments.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Assignments</h4></summary>
<ul>
<li>Use @-mention in notes and comments to notify teachers. List includes teachers of the assignment.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Annotated Feedback Assistant (AFA)</h4></summary>
<ul>
<li>Use ‘Check’ button for feedback and improve responses.</li>
<li>Access previous drafts with annotations.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Error Tracker Enhancements</h4></summary>
<ul>
<li>View modules with error counts under Questions tab.</li>
<li>Filter tracker by date range and tag. View questions and associated error counts.</li>
</ul>
</details></li>

<li><details><summary><h4 style="margin: 0; display: inline;">Starred Resources</h4></summary>
<ul>
<li>Students can star and unstar class group resources.</li>
</ul>
</details></li>

</ol>
