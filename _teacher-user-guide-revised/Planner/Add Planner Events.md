<h3>Create Class Events</h3>
<hr>
<p>Class Events improve the way teachers use SLS for in-class lessons by
allowing them to attach SLS resources and assignments to events in the
Planner. This will help students quickly access their learning materials
and easily toggle between SLS and physical resources in class.</p>
<h3>Creating a New Event</h3>
<hr>
<ol>
<li>
<p>There are three ways to add a <strong>New Event</strong>:</p>
<ol data-tight="true" class="tight">
<li>
<p>Click <strong>+ New Event</strong> from the Planner page,</p>
</li>
<li>
<p>Click <strong>+ New Event</strong> from the Planner tab within a Class Group,</p>
</li>
<li>
<p>Scroll to your desired time on the Planner and click at the time slot
to create a new event at that time.</p>
</li>
</ol>
</li>
<li>
<p>When adding a new event from the Planner page, select which Planner should
the new event be created for. You can do so from the <strong>Planner</strong> dropdown
list.</p>
<p><u>Note</u>: When a new event is added from the Planner tab within a Class
Group, the new event created will be for the selected Class Group.</p>
</li>
<li>
<p>On the New Event subpage, fill in the following details:</p>
<ol>
<li>
<p><strong>Planner</strong> Click the dropdown list to select which planner
you wish to create the New Event for. By default, the Personal Planner
will be selected.</p>
<p>When creating a new event from the Planner tab within a Class Group, the
Class Group Planner will be default Planner.</p>
</li>
<li>
<p><strong>Title</strong> - The event title will be pre-filled for you as
“Untitled”. Change the Title to one that is concise and relevant.</p>
</li>
<li>
<p><strong>Description</strong> - You can include details of the event here.</p>
</li>
<li>
<p><strong>Date &amp; Time</strong> - You can select how often the event repeats,
and the end date for the repeat.</p>
</li>
<li>
<p><u>Note</u>: The End Repeat field will be greyed out if None or Custom
are chosen for <strong>Repeat</strong>.</p>
</li>
<li>
<p><strong>Repeat</strong> - You can select how often the event repeats.</p>
</li>
<li>
<p><u>Note</u>: The <strong>End Repeat</strong> box will be greyed out if None
or Custom are chosen for <strong>Repeat</strong>.</p>
</li>
</ol>
</li>
<li>
<p>Click <strong>Create</strong> to proceed.</p>
<div class="isomer-image-wrapper">
<img style="width: 100%" height="auto" width="100%" alt="Create Class Events" src="https://www.learning.moe.edu.sg/images/2Teacher/P-NewEvent.png">
</div>
</li>
<li>
<p>For a Class Group Event, clicking the <strong>View Planner</strong> icon
will redirect you to the Planner tab within the Class Group.</p>
</li>
</ol>
