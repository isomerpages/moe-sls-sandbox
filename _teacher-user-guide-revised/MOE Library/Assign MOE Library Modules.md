<h2>Assign MOE Library Modules</h2>
<hr>
<h3>Assign MOE Module as Assignment</h3>
<hr>
<ol data-tight="true" class="tight">
<li>
<p>From the homepage, open the left menu and click Resources, followed by <strong>MOE Library</strong>.</p>
</li>
<li>
<p>Click the MOE Library <strong>Module</strong>  <strong>card</strong> that
you would like to view.</p>
</li>
<li>
<p>On the Module View page, click the <strong>Assign</strong> icon on the header</p>
</li>
<li>
<p>You may wish to rename the Assignment Title and edit the Permission Settings.
The following Module Permissions are available:</p>
<ol data-tight="true" class="tight">
<li>
<p><strong>Allow teachers to copy/assign/publish and students to copy this Module</strong>
</p>
</li>
<li>
<p><strong>Allow teachers and students to view Print-Friendly worksheet</strong>
</p>
</li>
<li>
<p><strong>Allow students to reattempt Module as self-study</strong>
</p>
</li>
</ol>
</li>
<li>
<p>Click <strong>Next</strong> to continue. This will lead you to the <a href="https://www.learning.moe.edu.sg/teacher-user-guide/assign/manage-assignments/" rel="noopener noreferrer nofollow" target="_blank"><u>Assignment Summary</u></a> page
where you can review the draft assignments and their settings before clicking <strong>Assign</strong> to
confirm.</p>
</li>
</ol>
<h3>Add MOE Module as Class Group Resource</h3>
<hr>
<p><u>Important</u>: If module permissions to allow teachers to copy/assign/publish
and students to copy this Module are not selected, it will not be possible
to add the Module as a Class Group Resource.</p>
<ol>
<li>
<p>Click the MOE Library <strong>Module</strong>  <strong>card</strong> that
you would like to view.</p>
</li>
<li>
<p>Click <strong>Overflow (3 dots</strong> icon) on the header to open the
right menu and click <strong>Add to Class Group Resources</strong>.</p>
<div class="isomer-image-wrapper">
<img style="width: 100%" height="auto" width="100%" alt="Assign MOE Library Lessons" src="https://www.learning.moe.edu.sg/images/2Teacher/AS-AssignMOE1.png">
</div>
</li>
<li>
<p>Select the Class Group(s), followed by <strong>Add</strong>.</p>
</li>
<li>
<p>You may wish to rename the Resource Title, and edit the Permission Settings:</p>
<ol>
<li>
<p>Module Permissions:</p>
<ol data-tight="true" class="tight">
<li>
<p><strong>Allow teachers to copy/assign/publish and students to copy this Module</strong>
</p>
</li>
<li>
<p><strong>Allow teachers and students to view Print-Friendly worksheet</strong>
</p>
</li>
<li>
<p><strong>Allow students to reattempt Module as Self-Study</strong>
</p>
</li>
</ol>
</li>
<li>
<p>Visibility</p>
<ol data-tight="true" class="tight">
<li>
<p><strong>Visible to students in Class Group</strong>
</p>
</li>
<li>
<p><strong>Notify Student(s)</strong> - this checkbox will be active if Resource
is set to be visible to students in Class Group.</p>
</li>
</ol>
<div class="isomer-image-wrapper">
<img style="width: 100%" height="auto" width="100%" alt="Assign MOE Library Lessons" src="https://www.learning.moe.edu.sg/images/2Teacher/AS-AssignMOE2.png">
</div>
</li>
</ol>
</li>
<li>
<p>Click <strong>Create</strong> to add the Module as a Class Group Resource.</p>
</li>
</ol>
