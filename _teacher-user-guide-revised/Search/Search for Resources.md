<h2>Using Search Bar from Homepage</h2>
<hr>
<ol data-tight="true" class="tight">
<li>
<p>Click the <strong>Magnifying Glass</strong> icon</p>
<div class="isomer-image-wrapper">
<img style="box-sizing: inherit; font-family: Lato, sans-serif; max-width: 100%; height: auto; display: inline; margin: auto; width: 1.5rem;" height="auto" width="100%" src="https://www.learning.moe.edu.sg/images/Icons/Search.svg">
</div>
<p>on the header of the homepage to open the Search Bar.</p>
</li>
<li>
<p>Enter your search terms, if any, in the Search Bar.</p>
</li>
<li>
<p>Press <strong>Enter</strong> to return your search results.</p>
</li>
</ol>
<p><u>Note</u>:</p>
<ul data-tight="true" class="tight">
<li>
<p>If you are unsure of what you are searching for, you can leave the Search
Bar empty and press <strong>Enter</strong> to return your search results.</p>
</li>
<li>
<p>You may also select the area of search and indicate whether you are searching
for the Title/Description/Module Tags/Subject/Level, a Content Map or a
specific Author/Collaborator.</p>
</li>
<li>
<p>You can also search directly from the various Resource pages (e.g. My
Drive, Community Gallery, MOE Library, App Library, External Resources).</p>
</li>
</ul>
<h2>Add Search Filters</h2>
<hr>
<ol>
<li>
<p>On the Search page, select the <strong>Area of Search</strong>, <strong>Subject</strong> and <strong>Level</strong> from
the dropdown list.</p>
</li>
<li>
<p>Under <strong>Area of Search</strong>, select from:</p>
<ul data-tight="true" class="tight">
<li>
<p><strong>Title/Description/Tags/Subject/Level</strong>
</p>
</li>
<li>
<p><strong>Content Map</strong>
</p>
</li>
<li>
<p><strong>Author/Collaborator</strong>
</p>
</li>
</ul>
</li>
<li>
<p>Under <strong>Subject</strong>, select from:</p>
<ul data-tight="true" class="tight">
<li>
<p><strong>Assigned Subjects</strong>
</p>
</li>
<li>
<p><strong><a href="https://www.learning.moe.edu.sg/teacher-user-guide/discover/follow-and-unfollow-subjects/" rel="noopener noreferrer nofollow" target="_blank"><u>Followed Levels</u></a></strong> (if
any)</p>
</li>
<li>
<p><strong>Other Subjects</strong>
</p>
</li>
</ul>
</li>
<li>
<p>Under <strong>Levels</strong>, select from:</p>
<ul data-tight="true" class="tight">
<li>
<p><strong>Assigned Levels</strong>
</p>
</li>
<li>
<p><strong>Followed Levels</strong> (if any)</p>
</li>
<li>
<p><strong>Other Levels</strong>
</p>
</li>
</ul>
</li>
<li>
<p>To add more search filters, click <strong>More Filters</strong>.</p>
</li>
<li>
<p>Under <strong>Resource</strong> (<strong>Resource Type</strong>), select
from:</p>
<ul data-tight="true" class="tight">
<li>
<p><strong>Modules</strong>
</p>
</li>
<li>
<p><strong>Questions (or Question Types)</strong>
</p>
</li>
<li>
<p><strong>Media (or Media Types)</strong>
</p>
</li>
<li>
<p><strong>Apps</strong>
</p>
</li>
<li>
<p><strong>Websites</strong>
</p>
</li>
</ul>
</li>
<li>
<p>Under <strong>Location</strong>, select from:</p>
<ul data-tight="true" class="tight">
<li>
<p><strong>My Drive</strong> - your own resources and those shared with you</p>
</li>
<li>
<p><strong>Community Gallery</strong> - Modules shared by teachers</p>
</li>
<li>
<p><strong>MOE Library</strong> - Resources produced by MOE</p>
</li>
<li>
<p><strong>App Library</strong> - App Resources integrated with SLS</p>
</li>
<li>
<p><strong>External Resources</strong> - Whitelisted websites that can be
embedded in SLS.</p>
</li>
</ul>
</li>
<li>
<p><u>Note</u>: Refine your search by using Guided Search.</p>
<h2>Add Topic Filters</h2>
<hr>
<ol>
<li>
<p>You may also select <strong>Add Topic Filters</strong> to filter according
to Topics or Sub-topics.</p>
</li>
<li>
<p><u>Note</u>: You may search for Resources based on Topics or Sub-topics
if they have been tagged to a Content Map.</p>
</li>
<li>
<p>To add topic filters, select <u>one</u>  <strong>Subject</strong> and <u>one</u>  <strong>Level</strong> from
the dropdown list.</p>
</li>
<li>
<p>On the Add Topic Filters subpage, select the relevant <strong>Content Map</strong> dropdown
list.</p>
</li>
<li>
<p>Select the checkbox to the left of the Topic, Subtopics, or Learning Outcome
to narrow down the search results.</p>
</li>
<li>
<p>Click <strong>Apply</strong> to view Search Results based on Topics of Sub-topics.</p>
</li>
</ol>

<h2>View Search Results</h2>
<hr>
<ol>
<li>
<p>You can sort the resources by&nbsp;<em>Relevance </em>to your search term(s), <em>Popularity</em> (only
in Community Gallery or MOE Library), or according to the date of the latest
edit.</p>
</li>
<li>
<p>Click the <strong>Module card</strong> to view Module Details. In Module
Details, you will be able to view the following information:</p>
<ul data-tight="true" class="tight">
<li>
<p>Resource Title</p>
</li>
<li>
<p>Resource Description</p>
</li>
<li>
<p>Teacher Notes (if any)</p>
</li>
<li>
<p>Module Location</p>
</li>
<li>
<p>Subject and Level (for Modules only)</p>
</li>
<li>
<p>Type of Resource</p>
</li>
<li>
<p>Number of Views (for Modules only)</p>
</li>
<li>
<p>Keyword Tags</p>
</li>
</ul>
</li>
<li>
<p><u>Note</u>: Resources that are downloadable can be downloaded from the
Resource card.</p>
<div class="isomer-image-wrapper">
<img style="box-sizing: inherit; font-family: Lato, sans-serif; max-width: 100%; height: auto; display: block; margin: auto; width: 805.333px;" height="auto" width="100%" alt="Search for Resources" src="https://www.learning.moe.edu.sg/images/2Teacher/D_Searchresources2.png">
</div>
</li>
<li>
<p>To view the Module Reviews, click the <strong>Overflow</strong> (<strong>3-dot</strong> icon)
found on the top right of the Module card, followed by <strong>See Reviews</strong>.
Click <a href="https://www.learning.moe.edu.sg/teacher-user-guide/discover/leave-reviews/" rel="noopener noreferrer nofollow" target="_blank"><u>here</u></a> to
learn how to leave a Review.</p>
</li>
<li>
<p>To make a copy of the Module, click the <strong>Overflow</strong> (<strong>3-dot</strong> icon)
found on the top right of the Module card, followed by <strong>Copy To</strong>.
Click <a href="https://www.learning.moe.edu.sg/teacher-user-guide/organise/copy-modules-within-my-drive/" rel="noopener noreferrer nofollow" target="_blank"><u>here</u></a> to
learn how to copy a resource to My Drive.</p>
</li>
<li>
<p>To open the Module, click on the <strong>Expand</strong> icon next to the
Module title.</p>
</li>
</ol>
