<h2>List Assignments</h2>
<hr>
<h3>Assignment Cards</h3>
<hr>
<ul data-tight="true" class="tight">
<li>
<p>Assignments that have been recently assigned (up to 3 days) will have
a New label on the Assignment card.</p>
</li>
</ul>
<p></p>
<ul>
<li>
<p>The progress bar in the Assignment cards shows the completion status of
students in the Class Group.</p>
<ul data-tight="true" class="tight">
<li>
<p>Yellow portion represents the proportion of students who have not started
the assignment.</p>
</li>
<li>
<p>Blue portion represents the proportion of students who have completed
the assignment.</p>
</li>
<li>
<p>Red portion represents the proportion of students whose assignments are
overdue.</p>
</li>
</ul>
</li>
<li>
<p>Modules with Sections will show the next available Section or Section
where the action is pending.</p>
</li>
<li>
<p>When an Assignment is set as an Assessment, the card will be reflected
in beige.</p>
<p></p>
</li>
</ul>
<h3>View All Assignments</h3>
<hr>
<ol>
<li>
<p>To view all Assignments, you can enter the Assignment page by either:</p>
<ul data-tight="true" class="tight">
<li>
<p>clicking <strong>Assignments</strong> on the homepage under the <strong>Assignments</strong> tab,
or</p>
</li>
<li>
<p>clicking <strong>Assignments</strong> from the left menu.</p>
</li>
</ul>
</li>
<li>
<p>You may search for Assignments on the Assignments page by entering the
title in the Search Bar. You may apply the <strong>Assignment Status</strong> and <strong>Class Group</strong> filters.
Click <strong>Apply</strong> to perform your selection.</p>
</li>
<li>
<p>For a more refined search, click <strong>Filter</strong> to filter the Assignments
by Assignment Status, Class Group, and Marking Status (for Assignments
with Teacher-Marked Quizzes only). Click <strong>Apply</strong> to perform
your selection.</p>
</li>
<li>
<p>You can choose to view your Assignments in card view</p>
<div class="isomer-image-wrapper">
<img style="box-sizing: inherit; font-family: Lato, sans-serif; max-width: 100%; height: auto; display: inline; margin: auto; width: 1.5rem;" height="auto" width="100%" src="https://www.learning.moe.edu.sg/images/Icons/Card.png">
</div>
<p>or in List view</p>
<div class="isomer-image-wrapper">
<img style="box-sizing: inherit; font-family: Lato, sans-serif; max-width: 100%; height: auto; display: inline; margin: auto; width: 1.5rem;" height="auto" width="100%" src="https://www.learning.moe.edu.sg/images/Icons/List.svg">
</div>
<p>.</p>
</li>
<li>
<p>Assignments in the List view are sorted according to the latest Start
Date. You may also sort the Assignments according to the Assignment Title,
and Due Date. Assessments in List View will be indicated by an orange tag
beside the Title.</p>
<p></p>
</li>
</ol>
<p><u>Note</u>: Students will see all their Assignments (except Assessments)
on the Assignments tab on the homepage if they are incomplete/overdue.
Overdue assignments remain accessible to students.</p>
<p><u>Did You Know</u>:</p>
<p>The Student Attempt URL can be shared with students so that they can access
the assignment directly after logging in. You may use any URL shortener
or QR code generator to make it easier for students to access the Assignment.
You can find the Student Attempt URL by clicking the <strong>Overflow</strong> (<strong>3-dot</strong> icon)
when inside an Assignment/Assessment.</p>
<h3>Add or Sort Assignments in Class Group</h3>
<hr>
<ol>
<li>
<p>You can add assignments to the Class Group from the Class Group page.</p>
</li>
<li>
<p>Access Class Groups from the left menu or by selecting the Class Group
(if pinned) on your homepage. On the Class Group page, click <strong>Add Assignment</strong> to
add the assignment:</p>
<ol data-tight="true" class="tight">
<li>
<p>From New Module</p>
</li>
<li>
<p>From My Drive</p>
</li>
<li>
<p>From Library</p>
</li>
<li>
<p>From Starred Resources</p>
</li>
</ol>
<div class="isomer-image-wrapper">
<img style="width: 100%" height="auto" width="100%" alt="Add Assignments to Class Group" src="https://www.learning.moe.edu.sg/images/2Teacher/AS-AddAssignment1.png">
</div>
</li>
<li>
<p>You may also add a new Category to your Class Group assignment. This can
be used to organise the Assignments for your Class Group.</p>
</li>
</ol>
<h3>Sort Assignments in Class Group</h3>
<hr>
<ol data-tight="true" class="tight">
<li>
<p>You can sort Assignments in Class Groups to find them easily.</p>
</li>
<li>
<p>On the Assignment tab in the Class group, select a category from the dropdown
menu. Click <strong>Apply</strong>.</p>
</li>
<li>
<p>Click <strong>Sort By</strong> and you can now sort the Assignments according
to Assignment title, due or start date.</p>
</li>
</ol>
<div class="isomer-image-wrapper">
<img style="width: 100%" height="auto" width="100%" alt="Sort Assignments in Class Group" src="https://www.learning.moe.edu.sg/images/2Teacher/as_addassignment3.jpg">
</div>
<h3>Sort Resources in Class Group</h3>
<hr>
<ol data-tight="true" class="tight">
<li>
<p>You can sort Resources in Class Groups to find them easily.&nbsp;</p>
</li>
<li>
<p>On the Resource tab in the Class Group, select a category from the dropdown
menu. Click <strong>Apply</strong>.&nbsp;</p>
</li>
<li>
<p>Click <strong>Sort By</strong> and you can now sort the Resources according
to modified date, date added or title.</p>
</li>
</ol>
