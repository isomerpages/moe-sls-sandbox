<h3>Pin Class Groups</h3>
<hr>
<ol data-tight="true" class="tight">
<li>
<p>From the homepage, open the left menu and click <strong>Class Groups</strong>,
followed by <strong>All Class Groups</strong> Alternatively, in the Class
Groups tab from the homepage, click Class Groups. By default, you will
be in the Current tab..</p>
</li>
<li>
<p>You can filter current Class Groups by Type and Role..</p>
</li>
<li>
<p>A Class Group can be pinned and unpinned by clicking the <strong>Pin</strong> icon
on the top right of the Class Group card.
<br>
</p>
<div class="isomer-image-wrapper">
<img style="box-sizing: inherit; font-family: Lato, sans-serif; max-width: 100%; height: auto; display: block; margin: auto; width: 825.328px;" height="auto" width="100%" alt="Pin Class Groups" src="https://www.learning.moe.edu.sg/images/2Teacher/O-PinnedClassGroups.png">
</div>
</li>
<li>
<p>Alternatively, enter a Class Group by clicking the <strong>Class Group card</strong> from
either the homepage (under the Class Groups tab) or Class Group page. Click
the <strong>Pin</strong> icon found beside the Class Group name.</p>
</li>
<li>
<p>Pinning a Class Group allows quick access to the Class Group. Below is
a list of interactions that take place when a Class Group is pinned.</p>
<ul data-tight="true" class="tight">
<li>
<p>Pinned Class Groups will:</p>
<ul data-tight="true" class="tight">
<li>
<p>appear first under the Class Groups tab on the homepage.</p>
</li>
<li>
<p>appear under Class Groups from the left menu.</p>
</li>
<li>
<p>appear at the top of the list of Class Groups on the Class Groups page.</p>
</li>
<li>
<p>appear at the top of the list of Class Groups when assigning a Module.</p>
</li>
<li>
<p>appear at the top of the list in dropdown fields involving Class Groups
(e.g. when viewing Class Group Notifications).</p>
</li>
<li>
<p>appear by default in the Planner.</p>
</li>
</ul>
</li>
</ul>
</li>
</ol>
<h3>Archive Class Groups</h3>
<hr>
<p>Class Groups (Group) created in SLS can be archived when they are no longer
needed.</p>
<ol data-tight="true" class="tight">
<li>
<p>To archive a Class Group, enter the Class Group by clicking the <strong>Class Group card</strong>.</p>
</li>
<li>
<p>Under the <strong>Admin</strong> tab, click <strong>Archive Group</strong>.</p>
</li>
<li>
<p>Archiving the Group cannot be undone. Once a Class Group is archived,
it will appear under the Past tab which will still be accessible to both
teachers and students. Assignments and other records associated with this
Class Group will also be accessible.</p>
</li>
<li>
<p>For an archived Class Group,</p>
<ul data-tight="true" class="tight">
<li>
<p>teachers will no longer be able to assign Modules to it, and</p>
</li>
<li>
<p>all users will not be able to create new Forum Posts and Polls.</p>
</li>
</ul>
</li>
</ol>
<h3>View Past Class Groups</h3>
<hr>
<p>At the start of each academic year, all Class Groups from the preceding
year will be found under the Past tab.</p>
<ol data-tight="true" class="tight">
<li>
<p>From the homepage, open the left menu and click <strong>Class Groups</strong>,
followed by <strong>All Class Groups</strong>. Alternatively, in the Class
Groups tab from the homepage, click <strong>Class Groups</strong>. By default,
you will be in the Current tab.</p>
</li>
<li>
<p>Click the <strong>Past</strong> tab. If you have past Class Groups from
multiple years, use the dropdown menu to navigate through the years.</p>
</li>
<li>
<p>You can filter past Class Groups by Role and year (and school, if you
have taught at more than one school).
<br>
</p>
<div class="isomer-image-wrapper">
<img style="box-sizing: inherit; font-family: Lato, sans-serif; max-width: 100%; height: auto; display: block; margin: auto; width: 825.328px;" height="auto" width="100%" alt="View Past Class Groups" src="https://www.learning.moe.edu.sg/images/2Teacher/O-PastClassGroups.png">
</div>
<p>
<br>
</p>
</li>
<li>
<p>Archived Class Groups will also be found under the Past tab.</p>
</li>
</ol>
<p><u>Note</u>: There is no way to delete a Class Group. Assignments, Resources,
Forum cards and Apps found within will still be viewable.</p>
