<h3>Reset Student Passwords for Classes</h3>
<hr>
<p>From R20, Form Teachers who are teaching at least one student in their
form class can reset the passwords of all students in their form class.</p>
<p>Owners and Co-teachers can reset the passwords of students in their Class
Groups created in School Cockpit. This is necessary for:</p>
<ol data-tight="true" class="tight">
<li>
<p>Students who have forgotten their SLS passwords and are unable to reset
them on their own</p>
</li>
<li>
<p>Onboarding a new student.</p>
</li>
</ol>
<p><u>Note</u>: You cannot reset the passwords of students in your Class
Groups created in SLS, but you can generate a Passcode (formerly known
as two-hour temporary password) to give them temporary access to the SLS.</p>
<h3>Access Reset Password</h3>
<hr>
<p>There are multiple ways to access the Reset Password page.</p>
<ul data-tight="true" class="tight">
<li>
<p>On the homepage, select a Class Group created in School Cockpit, then
select the Admin tab and click <strong>Reset Student Password.</strong>
</p>
</li>
<li>
<p>Open the left menu and click <strong>Administration</strong>, followed
by <strong>Reset Student Password</strong>.</p>
</li>
</ul>
<h3>Select Students</h3>
<hr>
<ol>
<li>
<p>Select a class from the dropdown list.</p>
</li>
<li>
<p>Select the students you will be generating the password for, by selecting
the checkboxes on the left.</p>
<p><u>Note</u>: You cannot reset the password of a locked student account.
Please approach your school's SLS School Administrator to do so.</p>
</li>
<li>
<p>Click <strong>Reset Password</strong>.</p>
<div class="isomer-image-wrapper">
<img style="width: 100%" height="auto" width="100%" alt="Reset Student Passwords for Classes" src="https://www.learning.moe.edu.sg/images/2Teacher/A-ResetPassword.png">
</div>
</li>
<li>
<p>On the confirmation prompt, verify that the correct number of students
has been selected.</p>
</li>
<li>
<p>Click <strong>OK</strong>.</p>
</li>
</ol>
<h3>Verification Code</h3>
<hr>
<ol>
<li>
<p>A verification code will be sent to your email address.</p>
<p><u>Note</u>: For security reasons, you will need to key in a verification
code to verify your identity. The verification code is valid for 10 minutes.
If the code has expired, you can request a new one by clicking <strong>Resend Verification Code</strong>.</p>
</li>
<li>
<p>Key in the verification code.</p>
</li>
<li>
<p>Click <strong>Proceed</strong>.</p>
</li>
<li>
<p>If successful, you will see a prompt indicating:</p>
<ul data-tight="true" class="tight">
<li>
<p>the number of students whose passwords have been reset,</p>
</li>
<li>
<p>the randomly generated password which you will need to inform your student(s)
and</p>
</li>
<li>
<p>the expiry date and time of this randomly generated password.</p>
</li>
</ul>
</li>
<li>
<p>Click <strong>OK</strong>.</p>
<p><u>Note</u>: This randomly generated password needs to be entered by the
student at the SLS login page and not the MIMS login page. It will last
for one year and can only be used once by each student. Upon logging in
with this password, students will be asked to set a new password.</p>
</li>
</ol>
